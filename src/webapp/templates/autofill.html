Autofill — Chrome extension

The extension fills application forms (Lever, Greenhouse, Ashby, and generic forms) with the facts from your Aawara resume — and nothing else. No data ever leaves your computer except to your own Aawara server for the resume payload.

1 · Generate your API token

This token lets the extension read your resume from your own Aawara instance. Treat it like a password.

{% if csrf_token() %}{% endif %} {% if has_token %} Token exists — you can regenerate it any time {% else %} No token yet {% endif %}

We only store a hash of the token. Once you leave this page the raw token is shown nowhere else — copy it now.

2 · Load the extension

  1. Open chrome://extensions in Chrome.
  2. Turn on Developer mode (top-right).
  3. Click Load unpacked and pick the extension/ folder in the Aawara repo.
  4. Pin the 🎯 Aawara Autofill extension.

3 · Set server URL + token in the options page

Right-click the extension icon → Options, then enter:

  • Server URL — your Aawara origin, e.g. http://localhost:8080 (no trailing slash).
  • API token — the token from step 1 (paste, don't type).
  • Save, then open any application form and click the extension icon → Fill form.

Fields are matched by label/placeholder/name heuristics. Only empty fields are filled — your typed answers are never overwritten.
